# ASCE 37 Wind & Snow

An interactive, single-page study aid covering construction-period wind factors, hurricane-season timing, and snow-load estimates for temporary structures.

Open `index.html` in a browser. Google Fonts are loaded from Google Fonts when a network connection is available; the page otherwise runs as a standalone HTML file.

This is an educational aid. Verify provisions against the applicable licensed standards, project requirements, and authority having jurisdiction before using them in design.
